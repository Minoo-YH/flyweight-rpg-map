
   Flyweight RPG Map - Final Notes

WHAT I DID
----------
I extended my previous Factory Method RPG Map Generator project.

I added JavaFX to display a random RPG map in a window.

I created TileGraphicFactory to share images between tiles of the same type.

I created MapRenderer to draw the map using JavaFX Canvas.

The Flyweight Pattern helps avoid creating the same image many times.

HOW TO FIND MY PROJECT
----------------------
Open Git Bash.

To go directly to my project folder from anywhere:

cd ~/Desktop/flyweight-rpg-map

To check my current folder:

pwd

IMPORTANT:
- The correct folder name is Desktop, not Dekstop.
- The ~ symbol means my home folder.
- I do not need to enter Desktop first.
- Always check that I am in flyweight-rpg-map before using Git commands.

HOW TO RUN
----------
1. Open Git Bash.
2. Go to the project folder:

   cd ~/Desktop/flyweight-rpg-map

3. Compile the project:

   mvn clean compile

4. Run the project:

   mvn javafx:run

RESULT
------
A JavaFX window opens and shows a random RPG map.

The terminal also shows the number of shared tile images.
